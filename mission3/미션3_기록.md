# 미션 3 기록

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| AI 1. 저장 기능이 없다. 다시 열면 모든 영화가 미분류로 돌아간다 | 같은 크롬에서 새로고침, 주소로 다시 열기 모두 영화와 등급이 남지 않음 | **반영** | 기획서 완성 기준에 "다시 열어도 영화와 등급이 남는다"고 적혀 있는데 지켜지지 않음 |
| AI 2. '처음으로'가 직접 추가한 영화를 지우지 않는다 | 영화를 추가한 뒤 '처음으로'를 눌렀더니 추가한 영화가 지워지고, 처음 영화 8개가 모두 미분류로 돌아감 | **보류** | 완성 기준에 없는 부분까지 점검한 건 좋았지만, 직접 해 보니 AI 말과 달리 지워졌음 |
| AI 3. 빈 제목을 막지 않아 기획서를 어긴다 | 제목을 비우고 '추가'를 눌렀더니 AI 말대로 됨 | **반영** | 기획서에는 빈 제목 이야기가 없으므로 "기획서를 어긴다"는 사실이 아님. 그래도 막는 게 좋으니 민수 님이 반영하면 좋겠음 |
| 동료 1. 휴대폰으로 열어 보니 불편했다 | 창 폭을 약 550px로 줄였더니 오른쪽이 잘림 (휴대폰으로는 열어 보지 않음) | **반영** | 기획서 완성 기준 "화면 폭이 좁아져도 오른쪽이 잘리지 않는다"가 지켜지지 않음. AI는 이 부분을 빠뜨렸고, 동료는 "불편했다"고만 해서 구체적이지 않음 |
| 동료 2. 카드 옮기는 게 처음엔 좀 헷갈렸다 | 나는 '선택한 영화 되돌리기' 버튼을 리셋 버튼으로 착각함 (동료가 말한 것과 같은 얘기인지는 모름) | **되묻기** | 어떤 부분이 헷갈렸는지 적혀 있지 않아 확인할 수 없음. 질문: 카드를 누르고 등급 글자를 누르는 방법과 끌어 놓는 방법 중 어느 쪽이 헷갈리셨나요? 헷갈린 버튼이나 화면이 있었다면 어디였나요? |
| 동료 3. 끌어서 옮기는 게 불편했다. 안 정한 영화가 맨 아래라 S칸까지 화면을 같이 올려야 한다 | 아래 카드도 S칸까지 잘 옮겨짐 | **보류** | 기획서대로 위에 등급 칸, 아래에 안 정한 영화가 있고 잘 옮겨짐 |
| 동료 4. 카드 색이 좀 칙칙하다 | 직접 보니 선명한 색을 잘 고름 | **보류** | 직접 보니 칙칙하지 않고 선명한 색을 잘 고름 |
| 동료 5. 영화 포스터 사진이 나오면 좋겠다 | 해 볼 것 없음 | **보류** | 기획서에 포스터 사진은 없었음. 기능에 꼭 필요한 것이 아니라 취향의 문제 |
| 동료 6. C칸은 굳이 없어도 될 것 같다 | 해 볼 것 없음 | **보류** | 기획서에 S·A·B·C로 나누겠다고 정한 기획자의 의도가 있음. 없애자는 건 개인 취향이라 반영할 이유가 없음 |

- 아무도 말하지 않았는데 내가 찾은 것:
  - **좁은 화면**: 창 폭을 줄였더니 오른쪽이 잘림 (AI는 "세 가지 외에는 완성 기준을 잘 지킨다"고 함)
  - **'선택한 영화 되돌리기' 버튼**: 기획서에 없는 버튼. 카드를 고르지 않고 버튼만 누르면 아래 화면에서는 반응이 보이지 않음 (안내 문구는 페이지 맨 위에 뜸). 카드를 먼저 고르면 잘 됨. 리셋 버튼으로 착각하기 쉬워 빼면 좋겠음
  - **미분류 영화 삭제**: 미분류 칸의 영화를 지우는 버튼이 없음. 제목에 오타가 나도 지울 방법이 없음
  - **미분류로 되돌린 영화의 자리**: 위로 올렸다가 다시 미분류로 내리면 맨 뒤가 아니라 원래 자리로 돌아감. 맨 뒤로 가면 좋겠음
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유:
  - 없음
