- AI가 물어서 내가 정한 것:
  - 누가 쓰나: 나 혼자, 본 영화 기록용
  - 기기: PC 브라우저 전용
  - 등급: S·A·B·C·D + 미분류
  - 옮기기: 끌어서 놓기
  - 영화: 기본 8편 + 제목 직접 입력으로 추가
  - 카드: 제목 글자만
  - 저장: 자동 저장 (같은 PC·같은 브라우저)
  - 그 밖에: 오타 카드 삭제, 전부 초기화(8편이 미분류로, 추가한 영화는 사라짐), 같은 제목·빈칸은 추가 안 됨
  - **뺀 것:** AI가 제안한 포스터, 인터넷 검색, 링크로 열기
  - **바꾼 것:** 기기 "둘 다" → PC 전용, 옮기기 "누르고 고르기" → 끌어서 놓기
- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과):
  - 기생충을 끌어서 S칸에 놓기 → S칸에 들어감 → 됨 / 됨
  - 새로고침 → 기생충이 S칸에 남음 → 됨 / 됨
  - "파묘" 추가 → 미분류에 새 카드 → 됨 / 됨
  - "파묘" 또 추가 → 추가 안 되고 안내 → 됨 / 됨
  - 빈칸으로 추가 → 카드 안 생기고 안내 → 됨 / 됨 (B는 이유까지 안내)
  - 카드의 × 누르기 → 그 카드만 사라짐 → 됨 / 됨
  - 전부 초기화 → 8편 모두 미분류, 추가한 영화 사라짐 → 됨 / 됨
  - 파일 더블클릭 → 서버·로그인 없이 열림 → 됨 / 됨
  - 참고: A를 클로드 아티팩트 화면에서 해봤을 땐 추가가 안 됐고, 파일로 내려받아 브라우저에서 여니 됐다.
- 선택한 파일명과 고른 이유:
  - **영화_B_초안.html**
  - 두 파일 모두 완성 기준을 통과했다. B는 끌 때 카드가 마우스를 따라와 옮기기 편하고, 옮기거나 추가할 때 알림이 떠서 됐는지 바로 알 수 있다.
