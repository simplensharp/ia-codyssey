# 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나
- 나 혼자 쓴다.
- PC 브라우저에서만 쓴다. 휴대폰은 지원하지 않는다.

## 2. 무엇을 하려고
- 내 영화 취향을 기록해 보관한다.
- 본 영화를 계속 쌓아 가며 등급을 매긴다.

## 3. 화면과 동작

### 화면 배치
- 위: S · A · B · C · D 등급 칸
- 아래: 미분류 칸
- 맨 아래: 영화 추가 입력창

### 티어
- 등급 칸은 S · A · B · C · D 5단이다.
- 등급을 아직 매기지 않은 영화가 모이는 **미분류 칸**이 따로 있다.
- 같은 칸 안의 카드는 들어온 순서대로 놓인다.

### 영화 카드
- 카드에는 **영화 제목 글자만** 보인다. 포스터는 넣지 않는다.
- 카드마다 **지우기 버튼**이 있다. 누르면 그 카드만 사라진다.

### 옮기기
- 카드를 **끌어서 등급 칸에 놓아** 옮긴다.
- 카드를 누르고 등급을 고르는 방식은 넣지 않는다.

### 영화 추가
- 제목을 직접 입력해 추가한다.
- 새로 추가한 영화는 미분류 칸에 들어간다.
- 이미 있는 제목은 추가되지 않게 막는다.
- 빈칸이나 공백만 넣고 추가를 누르면 카드가 생기지 않고 입력 안내가 나온다.
- 인터넷 검색 기능은 넣지 않는다.

### 초기화
- **전부 초기화** 기능이 있다.
- 누르자마자 실행한다. 다시 묻지 않는다.
- 추가한 영화는 지워지고, 기본 8편이 모두 미분류 칸에 있는 처음 상태로 돌아간다.

### 저장
- 자동 저장한다. 다시 열면 마지막 상태가 그대로 있다.
- 같은 PC, 같은 브라우저에서만 이어진다.

### 분위기
- 화면 분위기는 만드는 쪽(Claude)에 맡겼다.

### 넣지 않기로 한 것
- 같은 등급 안에서 순서 바꾸기
- 휴대폰 지원
- 누르고 고르는 방식
- 인터넷 검색, 포스터

## 4. 필요한 자료
처음부터 넣어 둘 기본 영화 8편 (처음에는 전부 미분류 칸에 놓인다):
1. 기생충
2. 인터스텔라
3. 라라랜드
4. 센과 치히로의 행방불명
5. 어벤져스: 엔드게임
6. 범죄도시
7. 타이타닉
8. 토이 스토리

그 밖에 따로 준비할 자료는 없다. 포스터와 외부 영화 데이터는 쓰지 않는다.

전달 형태: **HTML 파일**

## 5. 완성 기준
- [ ] 기생충 카드를 끌어서 S칸에 놓으면 S칸에 있다.
- [ ] 새로고침해도 기생충이 S칸에 남는다.
- [ ] 제목을 입력하고 추가를 누르면 미분류 칸에 새 카드가 생긴다.
- [ ] 같은 제목을 또 넣으면 추가되지 않는다.
- [ ] 빈칸으로 추가를 누르면 카드가 생기지 않고 입력 안내가 나온다.
- [ ] 추가한 카드의 지우기 버튼을 누르면 그 카드만 사라진다.
- [ ] 초기화를 누르면 8편이 미분류로 돌아가고 추가한 영화는 사라진다.
- [ ] 외부 파일·로그인·서버 없이 HTML 한 장으로 열린다.
